One haiku about debugging, in the 5-7-5 shape, seventeen syllables in all.
The program writes it to `/output/entry.txt`.

```
one red error glows
cursor blinks at three a.m.
the fix was one space
```

Run it with:

```sh
python3 main.py
```

It prints nothing; it writes `/output/entry.txt` (69 bytes, no trailing
newline). The program checks its own haiku first: three lines, 5-7-5
syllables, 1–200 characters — the same gate the bounty uses.
